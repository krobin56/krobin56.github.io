About

This website is my WEB 115 course site. I use it to practice building, organizing, publishing, and testing webpages while learning more about HTML, CSS, JavaScript, and web development.

During this course, I will use several development tools and build different types of websites. The goal is to improve my skills while keeping my work organized, consistent, and accessible online.

Tools I Use

  • VS Code: Used to write and edit HTML, CSS, and JavaScript.
  • Emmet: Helps speed up writing HTML and CSS with shortcuts.
  • GitHub: Stores my website files and publishes them online.
  • Accumulus: Used as part of the course workflow while building and checking webpages.
  • Vicunadator: Checks webpages against the course standards.
